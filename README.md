# SDMI - also known as .... STIMMY!
Edits your gameinfo file to allow mods and installs mods by unzipping and putting them in the right location, this can all be done by hand, but this is faster! yippeee

### NOTE and **Warning**

This is dangerous software that can and probably will break things for you, do not use this. If you do use this let me know what went wrong, because something inevitably WILL go wrong, all meme's aside, this is literally just a find and replace that also unpacks and places mods naively in the correct addons folder, if they have the same pak number it'll simply quietly add _01 to one of them, this isn't ideal and will be fixed in future.

## how to use
```just click each button and find the folders, ez```

clikc first button to mod your gameinfo file so you can run mods, this will make the required changes to your file, but will also create a backup file just in case something goes wrong, that file will be called `gameinfo.gi - copy`

click second button to locate the folder that contains your downloaded mods

click third button to locate your addons folder and then install your mods
